
  # Feminine Healthcare Color Palette

  This is a code bundle for Feminine Healthcare Color Palette. The original project is available at https://www.figma.com/design/4djU5iCm0wqJ5eIUf1Xddj/Feminine-Healthcare-Color-Palette.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deploying to GitHub Pages

  1. Push to the `main` or `master` branch.
  2. In the repository settings, set **Pages** source to **GitHub Actions**.
  3. The `Deploy to GitHub Pages` workflow builds and publishes `dist` automatically.
